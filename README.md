# button-plugin

给云崽（TRSS-Yunzai）里**已有命令**的回复挂上一层按钮，点一下直接执行，不用手打命令。

按钮走 QQ 官方的回调按钮，图片和键盘会合并在**同一条消息**里（需要 qq-bot 通道）。

## 安装

```
git clone https://github.com/ll-cn/button-plugin.git plugins/button-plugin
```

放进 `Yunzai/plugins/` 后发送 `#yz重启`，看到日志里的加载横幅即成功。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#按钮面板` / `#按钮帮助` | 打开入口面板（按钮由 miao 帮助自动生成） |
| `#按钮状态` | 查看开关、面板数量、miao 帮助条目数、配置路径 |
| `#按钮插件更新` | 从 GitHub 拉取新版本 |
| `#按钮插件强制更新` | 丢弃本地改动，对齐远程分支 |
| `#按钮插件更新日志` | 查看最近的提交记录 |

## 它是怎么工作的

- `app/decorate.js` 挂在 `Bot.on('message')` 上（比所有插件规则都早），把这次事件的
  `e.reply` / `e.group.sendMsg` 包一层，**任何插件**的回复都会经过它。
- 命中 `panels` 里的正则 → 用该面板的按钮；
- 否则只要回复里带图片 → 挂 `default.rows` 这套默认键盘；
- 回复里已经有按钮、或者带语音/视频/合并转发的，一律不动。
- 按钮的 `data` 就是命令文本。点击后 QQ 把它当作一条普通消息送进来，
  规则管道照常执行，所以回复里还会再挂一次按钮，可以一直点下去。

## 给桥打补丁（图片尺寸 + 回调按钮）

上游 `alemonjs-load-yunzai` 有两处会影响按钮体验，补丁脚本一次改完，自带备份、可重复执行：

1. **图片没有尺寸标注**。「图 + 按钮」合成一条只能靠 QQ 的 markdown 消息，桥把图片写成 `![图片](qqbot-media://…)`。
   官方语法是 `![文字 #宽px #高px](url)`，尺寸不能省：安卓端缺了就不按图片解析，只显示 `[图片]`；电脑端能显示但压成一条。
   补丁改成 `![图片 #0 #0](…)`（0 = 自动缩放）。
2. **不认 `callback` 字段**。不少插件写 `segment.button([{ text: '面板', callback: '#面板' }])`，
   桥只读 `data` / `action.data`，`callback` 被忽略 → 按钮退化成**指令按钮**，点了只把文字填进输入框（还不带 `#`）。
   补丁让 `callback` 生成回调按钮、`link` 生成跳转按钮。

在 alemon 根目录执行一次：

```bash
node plugins/button-plugin/scripts/patch-bridge.mjs          # 打补丁
node plugins/button-plugin/scripts/patch-bridge.mjs --revert # 出问题时还原
```

重启机器人后，`#按钮状态` 里会显示「桥图片补丁：已打」，插件随即自动切到 `merge`（图与按钮同一条）。
没打补丁时自动用 `split`，图与按钮分两条发。

## 配置

首次运行会生成 `config/config.yaml`（不进 git）。改完存盘即生效。

```yaml
enable: true           # 总开关
onlyGroup: false       # 只在群聊生效
exclude: []            # 命中的命令不挂按钮，例：["抽卡|十连"]
imageMode: auto        # auto 按桥补丁自动选；也可写死 split / merge
autoFromText: true     # 回复文字里出现 #命令 时自动把它加成按钮
maxAuto: 3             # 自动按钮最多几个
danger: "^#?(删除|解绑|清除|重置)"   # 命中的按钮变成指令按钮（点了只填入输入框）
upgradeButtons: true   # 其它插件发的指令按钮自动改成回调，点一下直接执行
keepInput: "^[#*]?(删除|解绑|绑定|登录|扫码|切换|设置|导入|添加|修改|清除|重置)"  # 这些保留指令按钮

default:               # 没有专门面板时，给带图回复挂这套
  enable: true
  rows:
    - ["#面板", "#更新面板"]
    - ["#体力", "#签到", "#帮助"]

panels:                # 专门面板：match 命中时替换默认键盘
  - match: "^#?(帮助|help|菜单|功能)$"
    source: miao       # 从 miao 的帮助配置自动生成
    groups: ["游戏面板与信息查询", "个人信息查询及签到"]
    extra: ["#更新面板", "#练度统计", "#今日素材"]
    limit: 15          # 最多 15 个（QQ 键盘上限 5 行 × 5 列）
    columns: 3
  - match: "扫码|绑定uid|绑定ck"
    rows:
      - ["#更新面板", "#绑定uid"]
      - ["#签到", "#帮助"]
```

## 注意

- 只有 **qq-bot（QQ 官方机器人）通道**会渲染原生按钮，其它通道会降级成 `[标题]` 文字。
- QQ 键盘最多 **5 行 × 5 列**，超出的按钮会被静默截断。
- 图片默认与按钮**分两条发**（`imageMode: split`）。合成一条要用 markdown 图片，而手机 QQ 会把它显示成
  `[图片]` 占位、电脑端也可能加载失败，所以默认不合并。
- 分两条时，同一条命令**只有第一条回复会拆**，后续回复原样发送。被动回复额度是按入站消息算的（5 分钟内 5 次），
  每条都拆会把多消息流程（扫码登录这类）的额度耗光，表现为后面的提示直接发不出去。
- 其它插件写的 `{ text, data }` 按钮默认是「指令按钮」，点了只把文字填进输入框；`upgradeButtons` 会把它们改成
  回调按钮直接执行，`keepInput` 里的命令（绑定、登录、删除等需要继续输入或需要确认的）保持原样。
- 拆两条会多消耗一次「被动回复」额度（同一条消息 5 分钟内最多 5 次）。插件本身回多条消息的流程
  （比如扫码登录）遇到 `40034128 被动回复时间或者次数超过限制` 时，把该命令加进 `exclude` 即可。
- 「危险命令」用指令按钮，点了只把命令填进输入框，需要自己按发送 —— 删除类操作就是要这一步。
- 更新完成后需要 `#yz重启` 才会用上新代码。

## 版本

版本号在 `package.json` 的 `version`，插件页脚自动跟着变。

- `0.0.1` 首个版本：装饰器挂按钮、帮助面板、更新命令
- `0.0.2` 图片与按钮改成分两条发（手机端能看到图了）；回复里出现的 `#命令` 自动变成按钮
- `0.0.3` 配 `scripts/patch-bridge.mjs` 修桥层的 markdown 图片尺寸，打上补丁后可回到「图 + 按钮」同一条
- `0.0.4` 补丁脚本同时修 `callback` / `link` 按钮字段，其它插件的回调按钮不再退化成指令按钮
- `0.0.5` 其它插件的指令按钮自动升级成回调按钮；分两条时同一条命令只拆第一条，避免耗光被动回复额度
